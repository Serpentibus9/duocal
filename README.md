# DuoCal

A shared calendar for two people, kept in your own Google Calendar.
This repository only holds the web app's files (HTML/CSS/JS). It contains no data,
no passwords and no keys. All calendar data stays in the users' private Google calendars.

* Sign-in: Google OAuth 2.0 in the browser; DuoCal never sees passwords.
* Access: decided by Google Calendar sharing.
* Security policy: strict Content-Security-Policy in index.html; scripts only from this site.
